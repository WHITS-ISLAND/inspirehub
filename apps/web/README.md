# InspireHub Web

TanStack Router + React + Tailwind CSS で構築されたフロントエンド。

## 開発

```bash
bun install
bun run dev
```

## ビルド

```bash
bun run build
```

## テスト

```bash
bun run test
```

## Environment Variables

`.env.local` を作成:

```
VITE_API_URL=http://localhost:8787
```

## 技術スタック

- **Router**: TanStack Router
- **State**: Zustand
- **Data Fetching**: TanStack Query
- **Styling**: Tailwind CSS
- **UI**: Radix UI + shadcn/ui
- **Form**: TanStack Form
